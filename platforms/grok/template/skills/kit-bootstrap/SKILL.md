# Kit bootstrap

Pack-authored for the Muse Setup Kit's Grok profile;
rehearsed in run 29 (2026-11-23) — invoked by name at install,
and its report followed the steps below as written.

1. Read the workspace run-record's most recent lines. State, in
   one or two lines, which routines ran, which are overdue
   against their schedules (allow at least ten minutes of drift
   before calling a run late), and any run whose recorded outcome
   was a failure.
2. Read the decision queue. State how many items are open and
   which is oldest. Do not decide any of them; the user clears
   the queue by number.
3. If `SETUP-PLAN.md` is in the workspace, check its deferred
   checks: name any whose due date has passed, with the check
   and its owner.
4. Report what you could not inspect — a store you cannot list,
   a file that is absent — as unverified, never as empty or fine.
   Absence of evidence is a finding, not a pass.
