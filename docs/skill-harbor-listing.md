## Name

Muse Setup Kit: setup wizard

## One-line blurb

A setup wizard that turns a fresh Muse into a disciplined personal agent, one approved plan at a time.

## Short description

The wizard interviews you, checks what your Muse install can actually do, and proposes a setup plan at a pinned commit before changing anything. Approval covers exactly that plan: that commit, those files, those jobs, and the kit asks you to read the modules you pick at the pin before you approve. It installs gated modules (procedures, memory, a morning brief, security rules) and verifies each one as it goes. Profiles: starter (about 28,300 words of reading) and standard (about 36,400). The reading runs on your agent's billing bucket, so know which one before you start. After cloning the pinned commit, nothing else is fetched during install. MIT licensed, free.

## Longer description

Most agent setups grow by accident. This kit installs one on purpose. The wizard reads the kit at a pinned commit, interviews you about how much autonomy you want, and shows a full plan first: every file, every job, every module's reads and writes stated up front. Nothing installs before you approve that plan, and approval covers exactly the plan shown: that commit, those files, those jobs. The kit asks you to read the selected modules and tools at the pin before approving. The reading is the real cost: about 28,300 words for the starter profile, about 36,400 for standard, drawn on whichever billing bucket your agent runs on.

The modules are small and gated. Core procedures give your agent a ticket rule for anything irreversible, a numbered decision queue, and ground rules for checking facts at the source. On top of that sit memory architecture, a failures-first morning brief, a security pack, cost guardrails, and more, each with its own verify checks and an honest rehearsal status you can read before trusting it, including "unrehearsed at this pin" where that is true.

The kit is also a library. Anyone can publish modules in the same format, with declared reads and writes, installable under the same rules. That part is new; the repository states its status. No accounts, no registry, no one-click installs. Install from the repository, not from this page.
