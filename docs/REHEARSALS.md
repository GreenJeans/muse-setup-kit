# Rehearsals

The kit's claim is "done means verified." This ledger is where
that claim is cashed: every rehearsal a fresh agent has run
against the kit, what it covered, and what it found. The wizard
states rehearsal status at selection time from each module's
`module.yaml` `rehearsed_at` field, which this ledger backs: "rehearsed at this
pin" when a row names the checkout, "rehearsed at <tag>; changed
since" when the module changed after its row, and "unrehearsed at
this pin — you would be the first" only when there is no row at
all.

Kept honestly, including the gaps. Early runs predate this ledger
and did not record per-module check counts; those rows say what is
known and no more.

- A fresh **full** install (all eleven modules) at any single pin.
- The wizard on a **small-group (Q1c)** interview.
- A module 05 **install** (its method — blind dual review — has
  been run against the kit itself in the rounds ROADMAP records
  by phase: Phase 2 (pre-v0.1), Phase 5 (adversarial, v0.3), two
  direction rounds, Phase 6 (v0.4) and Phase 10 (v0.8),
  Phase 11 (v0.9), and Phase 12 (the library) — six rounds;
  the install path has not).
- An uninstall of anything larger than the Starter profile, and
  any uninstall involving shares to revoke (run 8's install had
  none; the revocation steps are unrehearsed).
- A Lite → Full upgrade of module 08 (the F-steps are written
  from the Full install's steps; no agent has yet walked them
  from a live Lite install).
- A repair that actually restores a file (run 15's drill found
  no static-verbatim file to restore in a prose-only install;
  repair's class gates were exercised, its restore path was
  not).
- The tree at the v0.8 pin itself: modules 00, 01, 02, 03, 06,
  and 09 changed after runs 11–12 (the friction fixes, then the
  EX-018/019 review fixes), so their current text is unrehearsed
  at this pin — each module's `rehearsed_at` string says so.
- The tree at the v0.9 pin itself: modules 00, 02, and 10
  changed after runs 13–14 (the friction fixes, then the
  EX-020/021 review fixes), so their current text is unrehearsed
  at this pin — each module's `rehearsed_at` string says so.
- Pause/resume from a STATE card (run 19 copied the card;
  no run has yet paused and resumed a real task from one).
- The **Standard profile** (00+01+02+06+09) installed as a unit.

  are where breakage lives — and no ledger row installs Standard.

  install rehearsal runs at the release commit itself, so the
  release ships with at least one row at its own pin.
