# A worked example

Real artifacts from a real rehearsal — not illustrations written
for this page. In rehearsal run 8 (see `docs/REHEARSALS.md`), a
fresh agent installed the Starter profile into a sandbox for a
fictional solo user ("Robin," freelance projects), ran it, and
then uninstalled it. Before uninstalling, it preserved these
files. In run 6, another fresh agent installed module 08 at the
Lite tier for a different fictional user and staged a skill
change; that produced the last two artifacts.

Nothing here is edited except this page. If an artifact shows a
wart, the wart shipped in the rehearsal and the friction log is
what fixed it (run 8's log is summarized in the REHEARSALS row).

- **`setup-plan.md`** — the plan the wizard wrote and the user
  approved before anything was installed: capabilities, the
  interview answers, module choices with their verification
  results, the deferred-check ledger, and the installed-file
  baseline (note the two forms: hashed static files, and the
  queue and `JOBS.md` marked `accumulating`).
- **`morning-brief.md`** — the first brief the install produced,
  failures-first, including the queue drill item the rehearsal
  planted and cleared.
- **`jobs.md`** — the scheduler-of-record after install: the
  brief job and the monthly spend check that rides it.
- **`queue-item.md`** — a staged skill-write item as it appeared
  in the decision queue (run 6): the diff inline, its hash, the
  base hash it is void against, and the smallest ask.
- **`staged-proposal.md`** — the proposal behind that item:
  verbatim evidence, the preference-order justification, and the
  routing note, exactly as the reviewer staged it.
