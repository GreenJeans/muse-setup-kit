# Decision Queue

Continuously numbered. The user clears items by number in a single reply
(e.g. "1: yes, 3: park"). Numbers are never reused.

Non-urgent decisions only — time-sensitive, security, money-deadline, and
key-person items interrupt through the normal proactive channel instead.

For low-stakes items only, a default-if-no-reply and a resurface date are
printed. Silence is NEVER consent for a purchase, send, filing,
cancellation, or any irreversible action — those need a ticket (see
OPERATING_PROCEDURES.md).

Status key: open / decided / parked. When an item is decided or parked,
move it to Resolved below and keep its number.
