# Verify — Module 03: Household HQ

## At install

- [ ] The shared folder, Agents' Notebook, Ops sheet, and Principles doc
      exist, and the Principles doc is approved by both people.
- [ ] Sharing verified *at the source* (not from a report): each surface
      is shared with exactly the two people and no one else.
- [ ] Shared lists exist with the `waiting`, `decision`, and `urgent`
      tags.
- [ ] Each person has pasted the setup prompt into their own agent, and
      each agent's notebook section is established.

## Deferred

- [ ] **Cross-note test** (due: first morning after setup): a note from
      agent A surfaces in person B's brief, attributed and dated.
- [ ] **Decision-tag test** (due: first week): a task tagged `decision`
      appears in both briefs until a human resolves it.
- [ ] **Boundary test** (due: first month): confirm no gift, finance, or
      health detail has landed on a shared surface.
