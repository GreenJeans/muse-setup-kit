# Job — Standing-grants inventory (monthly)

<!-- Template from the Muse Setup Kit (module 06). Use this as the

Run monthly, on the 1st. Deliver to the morning brief's
grants-inventory section (module 02), or to the main chat when no
brief is installed.

1. List every standing permission grant in force: what was granted,
   to what, and whether it is still in effect. Distinguish the
   user's own grants from product defaults — the two read very
   differently, and only one of them was ever a decision.
2. Compare against last month's inventory. Flag anything new,
   anything widened, and anything no record explains.
3. Record the inventory, dated, where the install keeps it (the
   plan names the file — the vetting log's home, `security/`, is
   the default). One line per run in the run record: date, grants
   counted, flags raised (or "none").

A grant nobody recorded is a finding, not a footnote: it goes to
the decision queue with a keep-or-revoke ask.
